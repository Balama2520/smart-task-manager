Privacy Policy

Last updated: July 2026

Smart Task Manager ("the app") is built to work entirely on your own device. This page explains exactly what data exists, where it lives, and why.

No account, no server

There is no sign-up, no login, and no backend server. The app does not transmit your tasks, name, or usage anywhere. Nothing about how you use the app is collected, sold, or shared by the developer.

What's stored, and where

The app uses your browser's local storage, on your device only, for:

  • Your tasks (text, category, priority, due date, completion status)
  • The name you enter on first launch
  • Your theme preference (light/dark)
  • Your daily completion streak
  • Whether you've turned on due-date reminders

This data never leaves your device unless you explicitly use the "Export" button, which saves a JSON file that you control. Clearing your browser's site data, or uninstalling the app, permanently deletes it — there is no copy anywhere else to recover it from.

Voice input

The optional voice-input feature uses your browser's built-in speech recognition (the Web Speech API). Depending on your browser, converting your speech to text may involve sending audio to that browser vendor's own servers (for example, Google's, in Chrome) — this happens under the browser's own privacy policy, not the app's, and only while you are actively using the microphone button. The app itself never records, stores, or has access to raw audio.

Notifications

If you enable due-date reminders, the app uses your browser's local Notifications API to show a reminder while the app is open. No push notification server is used, and no data is sent externally to make this work.

Desktop widget, background sync, and push (dormant)

The app declares support for a few optional platform features so it can be packaged for app stores: a Windows desktop widget, background sync, periodic sync, and push notifications. None of these send or receive your task data. The desktop widget shows fixed sample text pointing you back to the app, not your real tasks. Background/periodic sync only re-run the same on-device due-date check described above. Push notifications have no server behind them and will never fire unless a future update adds one — this section will be updated first if that changes.

No analytics, no ads, no tracking

The app contains no analytics scripts, no advertising, and no third-party trackers. The only external network requests are for the Google Fonts stylesheet used to render the app's typeface.

Children's privacy

The app does not knowingly collect any personal information from anyone, including children, since no information is collected in the first place — everything stays in local browser storage on the user's own device.

Changes to this policy

If this policy changes, the "Last updated" date above will change accordingly.
